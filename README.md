# QPICK — интернет-магазина аудиоаксессуаров 

Тестовое задание: интернет-магазин аудиоаксессуаров на React + Vite + TypeScript.

## Запуск

```bash
npm install
npm run dev
```

## Технологии

- **React** — UI-библиотека
- **React Router** — роутинг (2 страницы: каталог и корзина)
- **TypeScript** — типизация
- **Vite** — сборка и dev-сервер
- **CSS Modules** — изолированные стили компонентов

## Функциональность

1. Две страницы: каталог (`/`) и корзина (`/cart`) через React Router
2. Возврат домой из корзины через лого и ссылку "Вернуться в каталог"
3. Счётчик товаров в шапке обновляется при нажатии 'Купить'
4. Сумма и количество пересчитываются при изменении корзины
5. Возможность удалять карточку товара из корзины товаров
6. Модальное окно-заглушка "В разработке" для будущей функциональности
7. Товары из массива products.ts, корзина в SessionStorage
